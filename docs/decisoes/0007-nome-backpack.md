# 0007 — Nome: Backpack

**Contexto:** o Jacques pediu para trocar o nome de Tooref para Backpack, com ícone de mochila em
traço branco sobre fundo laranja.

**Decisão:** nome, ícones, instalador (`Instalar Backpack.app`, rótulo `com.backpack.server`),
cabeçalho da API (`X-Backpack`) e variáveis (`BACKPACK_*`) trocados. O instalador novo remove a
instalação antiga (`com.tooref.server`). O repositório no GitHub foi renomeado para `backpack` na versão 1.0.0.

**Riscos registrados:** "Backpack" é o equivalente em inglês de "Mochila", nome antigo do MyLoot,
o que aproxima os dois projetos; e é um nome usado por outros produtos de tecnologia, o que
atrapalha ser encontrado. Não bloqueia uso pessoal; checar antes de divulgar.
