# Direção visual — Backpack

Referência fornecida pelo Jacques: `Referencia visual/Captura de Tela 2026-11-16 às 21.01.27.png`
(fora do controle de versão — é só inspiração, não um asset do produto).

Direção extraída da referência (não o print em si, que tem foto de pessoa real e não deve virar
asset do projeto):
- Glassmorphism: cards translúcidos com `backdrop-filter: blur`, fundo com imagem desfocada atrás.
- Janela com cantos arredondados grandes, sombra suave, "chrome" de topo minimalista.
- Paleta escura de base, com acentos de cor vibrantes nos cartões de KPI/status.
- Sidebar fina de ícones à esquerda.
- Tipografia grande e direta nos números principais (ex.: contagem de itens, progresso do dia).

Isso substitui o visual voxel/pixel-art do MyLoot por uma linguagem mais "dashboard de produto",
mais alinhada ao perfil de direção de arte do Jacques.
